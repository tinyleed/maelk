# mælk

Design prototype for **Mælk** — a warm, Nordic commerce-readiness product.

Current direction:

- lowercase `mælk` wordmark
- `æ` as the signature brand asset
- cream/cocoa/caramel palette
- sparse Milkglass controls for CTAs and readiness/progress states
- liquid motion means progress/readiness/transformation

Live preview target: GitHub Pages first, then `mælk.com` (`xn--mlk-yla.com`) once Namecheap DNS is pointed at the hosting target.
